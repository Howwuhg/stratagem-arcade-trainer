## 🌌 Welcome, Cadet of the Keyboard

Every drop into hostile territory begins with a single, decisive input sequence. **Stratagem Sage** is a tribute to that split-second choreography — the dance of directional keys and modifier taps that turns a chaotic battlefield into a canvas of controlled detonations, shield bubbles, and resupply beacons.

Where other trainers merely replicate button prompts, Stratagem Sage treats the art of the input string as a **mental sport**. It is part reflex drill, part memory gym, part loadout studio. Think of it as a compass that points not north, but toward mastery.

This repository houses the complete front-end experience, the practice engine, the loadout architect, and the reference compendium — all woven together into a single, elegant, browser-first application that runs anywhere a signal reaches.

## 🔥 Why Stratagem Sage Exists

There is a peculiar joy in the rhythm of a well-executed sequence. Muscle memory, once trained, becomes a superpower — the ability to summon thunder while your squad is still orienting their view. But building that memory requires repetition, and repetition without feedback is just noise.

Stratagem Sage was forged in that gap. It gives you:

- A **reflex chamber** where every input is measured, timed, and scored.
- A **living library** of every known sequence, cross-referenced and searchable.
- A **loadout studio** that lets you compose, save, and rehearse full kit rotations.
- A **progress ledger** that reveals how far you have traveled from novice to virtuoso.

The name "Sage" is deliberate. This is not a shortcut; it is a mentor.

## 🎮 The Practice Engine

The heart of the application is a **temporal judgment system**. Each drill presents a sequence, a countdown, and a stage. Your inputs are timestamped to the millisecond, then evaluated across three axes:

1. **Precision** — did the correct directional and modifier inputs land?
2. **Velocity** — how quickly did the full sequence complete?
3. **Consistency** — how much variance existed across your recent attempts?

Scores are blended into a single **Cadence Index**, a number that rises as you sharpen. The index is intentionally gentle at first and steepens as you improve — a curve that mirrors real skill acquisition rather than a flat grind.

### Drill Modes

- **Recon** — untimed, exploratory, perfect for newcomers mapping the layout.
- **Standard** — the classic timed challenge with three difficulty tiers.
- **Blitz** — compressed timing windows for the reflexes of veterans.
- **Endurance** — long-haul sessions that track fatigue and late-session accuracy drift.
- **Chaos Rotation** — randomized sequences that forbid autopilot.

### The Heatmap

After every session, a heatmap renders the keys you fumbled most. Over weeks, this becomes a fingerprint of your weaknesses — a map of the territory still unconquered.

## 📚 The Compendium

The Compendium is the reference wing of the application. It is part dictionary, part gallery. Each entry includes:

- The canonical glyph sequence
- Category tags (Offensive, Defensive, Utility, Support, Exotic)
- Cooldown metadata for planning rotations
- A short lore note for flavor
- Community-sourced tips for situational use

Search is instant and forgiving. Type partial names, category tags, or even describe what you want functionally — "shield bubble" or "area denial" — and the Compendium surfaces the closest matches.

---

## 🧠 Loadout Architect

A loadout is more than four slots. It is a philosophy of engagement. The Loadout Architect lets you:

- Assemble a kit from any four Compendium entries.
- Assign a **rotation order** with micro-timing prompts.
- Save unlimited named presets locally.
- Share a preset as a compact text string that others can paste in.
- Rehearse a preset as a chained drill that flows from one input to the next.

Think of it as a **choreography notebook**, where each preset is a short ballet of destruction and protection.

## 📱 Responsive Interface Design

The entire interface bends to fit the canvas in front of you — a phone in portrait, a tablet in landscape, an ultrawide monitor, or a handheld gaming display. Layouts are fluid, tap targets are generous on touch devices, and the keyboard overlay repositions itself near the bottom for thumb comfort.

There is no separate "mobile app" to reconcile. It is one codebase, one design language, three temperaments.

## ⚙️ Platform Availability

Stratagem Sage is a **progressive web experience**. Once loaded in a modern browser, it can be installed to a home screen or desktop and launched like any native application, complete with offline capacity for the Compendium and drill modes.

Supported engines include the evergreen releases of the major browsers. Legacy engines are supported on a best-effort basis.

## 🎨 Design Philosophy

Three principles govern every pixel:

1. **Clarity over decoration.** Ornaments never obscure information.
2. **Motion with meaning.** Animations communicate state, never fill silence.
3. **Respect for the player.** No dark patterns, no attention traps, no nagging.

The palette draws from deep field instrumentation — muted greens, amber alerts, and cool console blues — evoking a rugged terminal in a hardened bunker.

## 🔒 Privacy & Data Handling

By default, **all progress lives in your browser's local storage**. No account is required. No telemetry is transmitted. If you choose to enable cloud sync in a future release, it will be opt-in, explicit, and reversible.

We do not want your data. We want your cadence index to rise.

## 🚀 Getting Started Without the Hassle

The fastest path to the reflex chamber is a modern browser and a stable connection. Visit the hosted deployment, and the application loads into your session, ready to drill.

For those who prefer to run it locally, the project is a static bundle. Serve the directory with any lightweight HTTP server and navigate to the entry point. No build toolchain is mandatory; the assets are pre-compiled and versioned in the repository.

Configuration is accomplished through a single environment descriptor file at the root. Edit it to point at a different deployment, toggle feature flags, or adjust the default locale.

## 🧩 Extending the Compendium

Community members are encouraged to author additional Compendium packs. A pack is a JSON document with a defined schema:

- `pack_id` — a unique slug
- `locale` — the language of the entries
- `entries` — an array of sequence definitions

Validation is performed at load time, and malformed packs are quarantined with a clear error message rather than crashing the app. Contributions are welcome through the standard pull request flow.
